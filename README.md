# Painel Foda

Interface inicial independente para uma central de gestão responsiva.

## Estado atual

- Dashboard visual responsivo com navegação lateral.
- Áreas preparadas para clientes, revendedores, planos, financeiro, relatórios, automações, integrações, segurança e configurações.
- Dados reais ainda não conectados; não há registros de clientes nem transações fictícias apresentados como reais.
- Integração Supabase pendente: a organização atingiu o limite de projetos gratuitos ativos.
- Nenhuma credencial ou chave secreta deve ser publicada neste repositório.

## Visualizar

Abra `index.html` localmente ou habilite GitHub Pages nas configurações do repositório para publicar a interface estática.
